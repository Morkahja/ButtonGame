# Sounds

Wired in-game from `assets/sfx/`:

| Files | When |
| --- | --- |
| `impact1`–`impact4.ogg` | Random one on every target hit |
| `Bell1`–`Bell3.ogg` | Random one the first time a floater combo reaches **7+** |

Playback uses the Web Audio API (preloaded buffers, soft attack envelope, light pitch variance on impacts) so rapid hits stay usable.

## Free catalogs (if you want more later)

1. **[Kenney Interface Sounds](https://opengameart.org/content/interface-sounds)** — CC0 clicks / UI (OGG)
2. **[Kenney UI SFX Set](https://opengameart.org/content/51-ui-sound-effects-buttons-switches-and-clicks)** — CC0 switches (WAV)
3. **[The Motion Monkey Retro Arcade](https://www.themotionmonkey.co.uk/free-resources/retro-arcade-sounds/)** — 300+ arcade SFX
4. **[SFXMint UI](https://sfxmint.com/category/ui)** — large CC0 UI library

Also: [OpenGameArt.org](https://opengameart.org/) (CC0 filter), [Kenney.nl](https://kenney.nl/assets?q=audio), [Freesound](https://freesound.org/) (check license per file).
